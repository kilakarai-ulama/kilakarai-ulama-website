# கீழக்கரை நகர ஜமாஅத்துல் உலமா சபை — Static Website

இந்தத் திட்டம் HTML, CSS, JavaScript மற்றும் JSON அடிப்படையிலான, மொபைல்-நட்பு, தமிழ்/அரபி/ஆங்கில இணையதளத் தொடக்கத் தொகுப்பு.

## கோப்புகள்

- `index.html` — முகப்பு
- `about.html` — சபையைப் பற்றி
- `administration.html` — நிர்வாகம்
- `announcements.html` — அறிவிப்புகள் (JSON-இலிருந்து ஏற்றப்படும்)
- `activities.html` — மார்க்க மற்றும் சமூகப் பணிகள்
- `gallery.html` — புகைப்படங்கள்
- `contact.html` — தொடர்பு
- `assets/style.css` — வடிவமைப்பு
- `assets/site.js` — மொழி மாற்றம், மெனு, அறிவிப்புகள்
- `data/announcements.json` — மாதிரி அறிவிப்புகள்

## முக்கிய எச்சரிக்கை

இணையதளத்தில் உள்ள பெயர்கள், அறிவிப்புகள், முகவரி, நிர்வாக விவரங்கள் மற்றும் பிற உரைகள் மாதிரி/placeholder உள்ளடக்கங்கள். இவை உண்மையான சபை அறிவிப்புகள் அல்ல. பொதுமக்களுக்கு வெளியிடுவதற்கு முன் சபையால் சரிபார்த்து மாற்றவும். தற்போதைய நிர்வாகிகளின் பெயர்கள், புகைப்படங்கள், தொலைபேசி எண்கள் போன்றவை அனுமதி பெற்று மட்டுமே சேர்க்கப்பட வேண்டும்.

## கணினியில் உள்ளூராகப் பார்ப்பது

`index.html`-ஐ நேரடியாகத் திறந்து வடிவமைப்பைப் பார்க்கலாம். ஆனால் சில உலாவிகளில் `fetch()` மூலம் JSON படிக்கும்போது `file://` கட்டுப்பாடு இருக்கலாம். அறிவிப்புகள் சரியாகச் செயல்பட, உள்ளூர் HTTP server அல்லது GitHub Pages பயன்படுத்தவும்.

Python நிறுவப்பட்டிருந்தால் திட்டக் கோப்புறையில் terminal திறந்து:

```bash
python -m http.server 8000
```

பின்னர் உலாவியில் `http://localhost:8000` திறக்கவும்.

## GitHub Pages-இல் வெளியிடுவது

1. GitHub-இல் உள்நுழைந்து புதிய **Public repository** உருவாக்கவும். உதாரணப் பெயர்: `kilakarai-ulama-website`.
2. இந்த ZIP-ஐ unzip செய்து உள்ளே உள்ள கோப்புகள் அனைத்தையும் repository-யின் root-ல் பதிவேற்றவும். `index.html` root-ல் இருக்க வேண்டும்.
3. `data/announcements.json`-ஐத் திறந்து மாதிரி அறிவிப்புகளை சபை அங்கீகரித்த உண்மையான உரைகளால் மாற்றவும். `YYYY-MM-DD` தேதிகளைச் சரியான தேதிகளால் மாற்றவும்.
4. GitHub repository → **Settings** → **Pages** செல்லவும்.
5. **Build and deployment** பகுதியில் Source-ஐ `Deploy from a branch` எனத் தேர்ந்தெடுக்கவும்.
6. Branch-ஆக `main`, folder-ஆக `/(root)` தேர்ந்தெடுத்து **Save** அழுத்தவும்.
7. வெளியீடு முடிந்ததும் Settings → Pages பகுதியில் காட்டப்படும் இணையதள இணைப்பைத் திறக்கவும். முதல் வெளியீட்டிற்கு சில நிமிடங்கள் ஆகலாம்.
8. `https://<username>.github.io/<repository-name>/` என்ற வடிவில் URL இருக்கும்; உண்மையான username மற்றும் repository பெயரைப் பயன்படுத்தவும்.

GitHub Pages static files-ஐ வெளியிடும்; PHP போன்ற server-side code-ஐ இயக்காது. இந்தத் திட்டத்தில் database அல்லது Admin Panel இல்லை. அறிவிப்புகளை மாற்ற, `data/announcements.json` கோப்பைத் திருத்தி commit செய்ய வேண்டும்.

## அறிவிப்பைச் சேர்ப்பது

`data/announcements.json`-இல் உள்ள ஒரு object-ஐ நகலெடுத்து புதிய அறிவிப்பைச் சேர்க்கவும். ஒவ்வொரு அறிவிப்பிலும் `date`, `category_ta/en/ar`, `title_ta/en/ar`, `body_ta/en/ar`, `attachment` புலங்கள் இருக்க வேண்டும். JSON syntax-ஐச் சரியாக வைத்திருக்கவும்; ஒவ்வொரு பொருளுக்கும் இடையில் comma பயன்படுத்தவும் (கடைசி பொருளுக்குப் பின் கூடுதல் comma வேண்டாம்).
